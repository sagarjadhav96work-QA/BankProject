# Bank Management System

## Description

This project is a web-based Bank Management System tested using manual and automation testing techniques. It ensures the reliability, functionality, and security of banking operations.

## Modules

The system is divided into three main modules:

### 1. User

* Account registration and login
* View account details
* Check balance
* View transaction history

### 2. Admin

* Manage users and accounts
* Approve or reject account requests
* Monitor system activities
* Generate reports

### 3. Cashier

* Handle deposits and withdrawals
* Process transactions
* Update account balances
* Assist users with banking operations

## Features

* Account creation and management
* Transaction processing
* Report generation
* Role-based access (User, Admin, Cashier)

## Technologies Used

* Java
* Selenium
* TestNG
* MySQL

## Testing Scope

* Manual Testing (UI, Functional, Regression)
* API Testing
* Database Validation (SQL Queries)
* Security Testing (XSS, Input Validation)

## How to Run

1. Clone the repository
2. Open the project in Eclipse/IDE
3. Configure database (MySQL)
4. Run test cases using TestNG
